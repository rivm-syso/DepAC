
# Examples and Unit Tests

## Unit Tests

The DepAC project includes a comprehensive suite of unit tests that serve as the ground truth for the model's scientific and computational behavior. These tests validate the core routines, input validation, error handling, and calculation modules, ensuring that DepAC produces reliable and reproducible results. By passing all unit tests, the model demonstrates compliance with its scientific specifications and expected outputs.

Unit tests are maintained in the `test` directory and are run automatically as part of the continuous integration (CI) pipeline. Users and developers are encouraged to review and extend these tests to cover new features or scientific scenarios.


## Implementation Examples

In addition to unit tests, the DepAC repository provides example implementations that demonstrate how the model can be integrated into user projects. These examples illustrate typical usage patterns, input preparation, and result interpretation, helping users adapt DepAC to their own workflows and scientific needs.

Example scripts and documentation are available in the `example_packages` folder. These examples are designed to be clear, concise, and easily modifiable for custom applications.

Documentation is provided by the `README.md` file in the `example_packages` folder
